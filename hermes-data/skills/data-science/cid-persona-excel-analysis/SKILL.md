# CID 人群画像 Excel 分析技能

## 触发条件
当用户上传或提及 "CID title.xlsx"、"人群画像"、"CID" 相关Excel文件进行分析时使用此技能。

## 核心工作流程

### 1. 检查文件结构
```python
import pandas as pd

xlsx = pd.ExcelFile('文件路径.xlsx')
print(f"Sheets: {xlsx.sheet_names}")

# 读取人群画像 sheet（注意：header=None，使用index读取）
df = pd.read_excel('文件路径.xlsx', sheet_name='人群画像', header=None)
print(f"Shape: {df.shape}")
```

### 2. 理解Excel的层级结构（关键）
该文件的结构是**行式层级**，不是传统表格：
- **列1 (index 1)**: 一级分类（大类，如"人口统计学"）
- **列3 (index 3)**: 二级分类（如"年龄段细分"、"婚姻状态"）
- **列5 (index 4)**: 具体标签值
- **列6 (index 5)**: ONE_ID（该标签覆盖的人数比例）
- **列7 (index 6)**: RATIO（= TGI，>100表示高于平均水平）
- **列8 (index 7)**: TGI值

⚠️ **重要**：由于存在合并单元格，某个一级分类下的所有标签值共享同一个"一级分类"名称。
需要用 `current_cat` 和 `current_subcat` 变量追踪当前上下文。

### 3. 解析代码模板
```python
current_cat = ""
current_subcat = ""

for i in range(len(df)):
    row = df.iloc[i]
    c1 = str(row[1]).strip() if pd.notna(row[1]) else ""
    c3 = str(row[3]).strip() if pd.notna(row[3]) else ""
    c5 = str(row[5]).strip() if pd.notna(row[5]) else ""
    c6 = row[6] if pd.notna(row[6]) else ""
    c7 = row[7] if pd.notna(row[7]) else ""
    
    # 更新当前分类
    if c1 and c1 not in ["nan", "定义\n\n标签"]:
        current_cat = c1
        current_subcat = ""
    if c3 and c3 not in ["nan"]:
        current_subcat = c3
    
    # 有数据的就是有效字段
    if c5 and c5 not in ["nan", "ONE ID"] and c6:
        print(f"{current_cat} > {current_subcat} > {c5}: N={c6}, TGI={c7}")
```

### 5. 人生阶段 vs 年龄段细分（重要区别）
- **人生阶段**：用户的业务定义标签（7个），包括"适婚时期"、"学生时期"等
- **年龄段细分**：纯年龄划分（8档），更精确但缺乏业务语义
- 两者高度相关但不完全重叠，部分人群的人生阶段可能为"未知"

### 6. 年龄段格式
使用左闭右开区间: `[18,25)` 而不是 `18-24`

## 重要概念：基础维度 vs 叠加筛选

### 基础维度（构建二维象限沙盘）
| 维度 | 说明 |
|------|------|
| **人生阶段** | 用户业务定义的7个阶段 |
| **城市等级** | 一线、新一线、二线、三线、四线/五线 |

这2个维度构建5×5=25个坐标点的基础人群矩阵。

### 叠加筛选维度（品牌个性化配置）

这些维度可以叠加在基础矩阵上，实现人群精细化：

| 优先级 | 维度组 | 核心字段 | 业务意义 |
|--------|--------|---------|---------|
| ⭐⭐⭐ | 生命周期事件 | 生育情况、子女年龄、子女教育阶段 | 母婴/教育行业必选 |
| ⭐⭐⭐ | 经济实力 | 月收入（6档）、月支出（8档） | 消费能力分层 |
| ⭐⭐ | 职业状态 | 工作状况、在职/待业/退休、工作年限 | 收入稳定性 |
| ⭐⭐ | 设备属性 | 手机品牌、操作系统 | 投放精准定向 |
| ⭐⭐ | 固定资产 | 房产套数（0/1/2/3+）、车产（低/中/高） | 财富积累标签 |
| ⭐ | 金融行为 | 有无车贷/房贷/消费贷、信用卡活跃度 | 负债压力/信用 |
| ⭐ | 保障意识 | 寿险/意外险/车险用户 | 风险管理需求 |

### 叠加筛选业务价值
- **高端品牌**：叠加"月收入￥24000+" + "房产2套+"
- **母婴品牌**：叠加"生育情况=已育/二胎" + "子女年龄=1-3岁"
- **金融产品**：叠加"有房贷" + "信用卡活跃" + "月支出￥3000+"

## 验证步骤
1. 确认 sheet 数量和名称
2. 检查 Row 0-1 的表头定义
3. 搜索 "人生阶段" 确认位置
4. 提取年龄段、生育情况等核心维度的数据范围
